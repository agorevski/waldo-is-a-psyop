# Worked Example: the Beach Hook Table

This is the verified hook table for the first case file, `scenes/beach/scene.jpg` (originally `waldo_beach.jpg`). It is an EXAMPLE of what [../hook-discovery.md](../hook-discovery.md) produces; record each new scene's table in `scenes/<id>/hooks.md` in the same format. Do not reuse these regions for any other image.

The image is exactly **1500 × 937 px**. All regions are `{x, y, w, h}` in these pixels. Each item below was confirmed at 4–10× zoom.
